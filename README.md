# College Attendance Tracker

A wrapper around the college website that fetches your attendance and shows it
properly, with clear analytics.

It logs into the college portal with your enrollment number, pulls your profile
and attendance records, and presents them in a cleaner interface with
attendance views and analytics.

```text
backend/    Express + TypeScript API and college portal integration
frontend/   React + Vite client
deploy/     Caddy and systemd configuration
```
